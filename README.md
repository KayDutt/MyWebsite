# Jekyll Website

This repository contains a Jekyll site (source) for a personal or project website.

Contents
- `_config.yml`, `_includes/`, `_layouts/`, `_posts/` — Jekyll source files
- `index.markdown`, `about.markdown`, and HTML pages
- `src/` — additional source code (contains a `ruby-3.3.6` tree)

Notes
- The generated site `_site/` is ignored via `.gitignore`.
- Keep `Gemfile` and `Gemfile.lock` to reproduce the Ruby/Gem environment.

How to build locally
1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve` to serve locally.
